# LBG Banking DevOps Project

A demo digital banking application built using Python Flask microservices.

## Microservices

| Service | Port |
|---|---|
| Customer Service | 5000 |
| Account Service | 5001 |
| Payment Service | 5002 |
| Notification Service | 5003 |

## Technology Stack

- Python
- Flask
- Git and GitHub
- Docker
- Kubernetes
- Azure Kubernetes Service (AKS)
- Azure DevOps
- Terraform

## Project Goal

To implement a microservices-based banking application and
build an end-to-end DevOps deployment pipeline.
