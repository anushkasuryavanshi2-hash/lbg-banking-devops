
# LBG Banking DevOps Project

## Project Overview

A demo digital banking application built using a microservices architecture and DevOps practices.

The project demonstrates how to develop, containerize, deploy, and manage banking application services using cloud and DevOps technologies.

## Microservices

| Service | Description | Port |
|---|---|---|
| Customer Service | Customer information | 5000 |
| Account Service | Account information | 5001 |
| Payment Service | Payment information | 5002 |
| Notification Service | Banking notifications | 5003 |

## Technology Stack

- Python
- Flask
- Git and GitHub
- Docker
- Kubernetes
- Helm
- Microsoft Azure
- Azure DevOps
- Terraform

## Implementation Roadmap

1. Local microservices development
2. Docker containerization
3. Azure Container Registry
4. Kubernetes deployment
5. Azure Kubernetes Service
6. Helm deployment
7. Azure Database integration
8. Azure Key Vault
9. Terraform infrastructure provisioning
10. Azure DevOps CI/CD pipelines
11. Monitoring and observability
